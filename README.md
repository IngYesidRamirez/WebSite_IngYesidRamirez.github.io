# CV Website — Yesid David Ramírez
## Versión 2 — Project Manager / QA Manager

Website multipágina responsive preparado para GitHub Pages.

### Publicación
1. Crear un repositorio público en GitHub, por ejemplo `yesid-cv`.
2. Subir el contenido de esta carpeta conservando las carpetas `css`, `js` y `documents`.
3. GitHub → Settings → Pages → Deploy from a branch → `main` → `/ (root)`.
4. Guardar. GitHub generará la URL de GitHub Pages.

### Nota
El PDF original del CV está incluido en `documents/CV_Yesid_Ramirez.pdf`.
